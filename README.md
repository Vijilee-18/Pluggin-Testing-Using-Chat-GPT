# Expense Tracker

A responsive personal expense tracker built with HTML, CSS and vanilla JavaScript.

## Features
- Add income and expense transactions
- Categories and dates
- Balance, income and expense summaries
- Search and filter
- Delete individual transactions or clear all
- Expense breakdown by category
- Browser localStorage persistence
- Responsive desktop/mobile design
- No framework or backend required

## Run
Open index.html in a browser.

## Future
The frontend can later be connected to Flask + SQLite for authentication, server-side persistence, monthly reports and multi-device access.
